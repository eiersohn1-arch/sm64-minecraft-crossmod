# Hybrid camera behavior

F5 follows the normal Minecraft three-view cycle:

1. first person;
2. third person from behind;
3. third person from the front.

First person uses the real vanilla Minecraft hand/item renderer in the
screen-space overlay.

Third-person camera positions are generated by the visible SM64 host. Before a
camera position is accepted, the host walks from the Steve/Mario focus point to
the desired position and tests native SM64 wall, floor and ceiling collision.
If the camera would enter geometry it stops at the last safe point.

Mouse attack/use is separated from original SM64 B input. Right-click therefore
does not punch while placing a Minecraft block. Empty-hand left-click may still
produce native B for original grab interactions, and `V` is a dedicated
native-SM64 B fallback for special original-game mechanics.
